# Product

LIMIT U: 현실적이고 직접적인 커리어 성찰 도구. 비하 없이 현재 행동의 병목과 다음 실행을 제시합니다. 예언·확률·자격 판정 서비스가 아닙니다.

첫 상품 Career Destiny Report. Landing → Auth 또는 자격증명 없는 Demo → 6단계 입력 → 서버 계산 → Dashboard → 3경로/계획상 Critical Age → 행동 → 25개 상세 관점. Demo Checkout은 비용과 유료 권한 없이 simulated 상태를 반환합니다.

내부 1~5 단계는 사용자에게 노출하지 않는다. 실제 역할과 전문가/관리 경로에 따라 책임 범위로 번역하며 회사 직급의 확정 예측으로 사용하지 않는다. Baseline은 현재 행동, Improved는 12개월 행동 실천, Aggressive는 24개월 이상 역할 확대·자원 확보 조건이다. 최신 정형 모델은 [CAREER_MODEL.md](CAREER_MODEL.md)를 기준으로 한다.

성별·이름은 커리어 판정에 사용하지 않습니다. 교육, 소득 일부 필드는 현황 기록을 위한 것으로 자동으로 능력을 단정하지 않습니다. 손금/사주 신호는 작은 상징적 가중치이며 실제 경력과 행동 증거가 중심입니다.

한국어 mobile-first charcoal/ivory/gold 디자인. 독립 SVG 차트와 네이티브 폼 요소로 라이브러리 무게를 줄였습니다.
